# HomeBrain Weather System

This tutorial uses the real signed-in Freestone HomeBrain session on the iPad Simulator. It shows current non-credentialed data from the saved Lehi weather location, the connected Tempest station, and the connected Govee indoor-air monitor. No password, token, precise coordinates, or street address appears in the video.

The final master is 1920 by 1080 at 30 fps. A deterministic derivative is also produced at 1024 by 600 and 30 fps while preserving the complete master frame.

Narration uses the ElevenLabs API with the `Evening British Female` voice and model `eleven_v3`. Every section uses `[calm, measured, and matter-of-fact]`. Background music reuses the approved restrained instrumental bed from the HomeBrain Security tutorial.
